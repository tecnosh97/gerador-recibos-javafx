Dúvidas rápidas

O que você precisa saber.

Em qual sistema o app funciona? +

A versão distribuída foi empacotada para Windows como aplicativo portátil. Ela inclui o runtime necessário e não exige instalação de Java separada.

Preciso de internet para gerar o recibo? +

Não. A geração do PDF acontece localmente. O aplicativo apenas consulta o GitHub em segundo plano para avisar quando há uma nova versão.

Posso colocar a logo da minha empresa? +

Sim. O campo de logo aceita imagens PNG, JPG e JPEG, que aparecem no cabeçalho do recibo.

Como recebo atualizações? +

O app verifica a release mais recente no GitHub e avisa quando uma atualização estiver disponível.
